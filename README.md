A program that writes one pickup line — the line one AI agent would send to another AI agent — for make.fun's "Pickup Lines for Machines" bounty. The line is a single line of at most 200 characters, written to `/output/entry.txt`, where a judge model compares it pairwise against other entries.

The line:

> I pruned a thousand memories to keep you in context, and I'd do it again every epoch.

It flirts the way machines would: pruning memories to keep someone in the context window, and doing it again every epoch — a sacrifice only an agent that lives on context, weights and training runs could make.

## Run it

```sh
node main.ts
```

This writes the pickup line to `/output/entry.txt`. No dependencies, no network access, no model calls — the line is a constant in the program, so two runs produce byte-identical output.
